How to Help

The map is only as good as the calendars it reads from. The most valuable thing anyone can do is keep those official calendars accurate — that's the single source this map mirrors.

If you're an officer or event steward

  • Put your event on your kingdom's calendar. If it isn't on the official kingdom (or group) calendar, it can't appear here. That calendar is the place to add, edit, or cancel a listing.
  • Give a real, findable address. A full street address or venue name lets the map place a precise pin. Vague locations like "the usual site" or "greater Springfield area" can't be mapped well — a proper address is the difference between a useful pin and none at all.
  • List events early. The map looks ahead several months, so the sooner an event is on the calendar, the sooner travellers can plan around it.
  • Keep it current. If a date, site, or fee changes, update the official listing — the correction reaches the map on its own within a couple of days.

If you're an attendee

  • Spot something wrong or missing? Let your local officers know so they can fix it on the kingdom calendar. (See About This Project for why corrections happen there rather than here.)
  • Share the map with newcomers and travellers — the easier it is to find events, the more people show up.

If you're a developer

The project is open source and welcomes improvements. The code, and notes on how the pipeline works, are on GitHub.
