About This Project

This is a free, unofficial map of upcoming Society for Creative Anachronism events across the Known World. It exists to answer one question as easily as possible: what's happening near me, and when?

Where the events come from

The map doesn't host its own event listings. Every event you see is pulled automatically from a kingdom's or group's own public calendar — the same official calendars the kingdoms already maintain. A program gathers those listings every couple of days, looks up each event's location so it can be placed on the map, and refreshes the pins. Nothing is entered by hand.

Found something wrong, or your event isn't here?

Because the map only mirrors the official calendars, that's where a correction is made — not here. If an event is missing, in the wrong place, or out of date:

  • Ask whoever maintains your group's or kingdom's calendar — usually the webminister, calendar deputy, or seneschal — to add or fix the event on the official kingdom calendar.
  • Once it's corrected there, it flows onto this map automatically, usually within a couple of days. There is no separate form to submit to this site, and no one to email — keeping the official calendar right keeps the map right.

Please double-check before you travel

This project is run by volunteers and is not affiliated with the SCA, Inc. or with any kingdom. Dates, sites, and fees change, and automated location lookups are occasionally imperfect. Always confirm the details on the official event listing or with the event steward before making plans.

The map is open source. If you're technically inclined and want to see how it works (or help improve it), the code lives on GitHub.
